04 / QUESTIONSNO FINE PRINT

Be clear.
Then build.

Proof is useful when the limits are visible too.

01 Is the hosted app using real GEN? +

No. The hosted workspace simulates GEN balances and settlement. The GenLayer contract candidate has not been deployed or connected to the hosted app.

02 What can Clintr verify? +

The current demo supports a byte histogram and fixed-weight integer neural model. It verifies bytes and recomputes these deterministic results. A hash alone cannot prove arbitrary AI work was correct.

03 Is the hosted data on IPFS Cluster? +

The local stack pins raw CIDs across three IPFS Cluster peers on one host. The hosted demo still uses Netlify Blobs as a CID-checked mirror.
