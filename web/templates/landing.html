01 / HOW IT WORKS

From request to result,
with a proof trail.

Every job has a clear path through the grid. The current demo runs bounded, reproducible workloads, including a small integer neural model, so results can be independently checked.

↗

Submit a job

Upload input data, choose the workload and deadline, and receive a job ID with a content reference.

02

An available node processes the work and stores the output by content ID with a proof hash.

03
