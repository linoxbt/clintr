04 / GOOD QUESTIONS

What Clintr does today.

Clear claims make the proof more useful. Here is the boundary between the working demo and the planned network.

Is the hosted app using real GEN? +

No. The hosted workspace simulates GEN balances and settlement. The GenLayer contract candidate is in the repository, but live staking, slashing, and reward transactions are not connected to the hosted app.

What can Clintr verify? +

The demo supports a byte histogram and a fixed-weight integer neural model. It verifies their input and output bytes and recomputes the deterministic result. A hash alone cannot prove an arbitrary AI workload was run correctly.

Where is job data stored? +

The local Compose stack pins raw CIDs across three IPFS Cluster peers on one host. The hosted demo currently stores bytes in Netlify Blobs and serves a CID-checked mirror; it is not yet backed by that Cluster.
